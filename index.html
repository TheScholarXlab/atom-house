Guide

Atom House is a hands-on lesson for one child or a small group, with an adult beside them. The atom itself is the control of error, so the child can see when it is wrong without being told.

  1. Name it (Explore). Place a proton and tap it: "This is a proton." Do the same for the neutron, electron, nucleus and shell.
  2. Recognise it (Words). Ask "Show me the nucleus" on the board. Use the Words cards to practise the terms, then cover the definitions.
  3. Recall it (Build). When an atom settles, press Name the parts. The prompt asks the child to point to parts without labels.

How the atom tells the child it is wrong: the name plate follows the number of protons, the charge chip compares protons and electrons, the nucleus wobbles while they do not match, and the outer ring glows green only when the build matches the card.

Shell rule: this model fills 2, 8, 8, 2, which is correct for the first 20 elements. The third shell can hold more than 8 in reality; that comes after calcium.

In Build, neutron counts use the most common isotope of each element. In Explore, the name plate shows the exact nuclide you made and whether it is stable, radioactive or not found in nature.

Relatives teaches three relationships between nuclides. Isotopes: same protons, different neutrons. Isobars: same mass number, different protons. Isotones: same neutrons, different protons. The comparison table shows which numbers match the card; the child works out which matches the relationship needs. Only real nuclides count: the stable ones for the first 20 elements, plus tritium, carbon-14 and potassium-40.
